Build error fixed from provided CI log (2026-09-29).

Root cause:
OctagonCheckBox.setChecked() accepts exactly one boolean parameter.
OverlayService.java incorrectly called it with (boolean, boolean) at:
- checkTactix.setChecked(false, false)
- checkGlobalSens.setChecked(true, false)

Fixed to:
- checkTactix.setChecked(false)
- checkGlobalSens.setChecked(true)

GamingSwitch is separate and DOES support setChecked(boolean, boolean), so its
two-argument calls were intentionally left unchanged.

I could not execute a complete Gradle build in this environment because the
project's Gradle wrapper distribution (8.1.1) is not cached and outbound network
access is unavailable. The supplied CI log reaches Java compilation and reports
only the two OctagonCheckBox errors above.
