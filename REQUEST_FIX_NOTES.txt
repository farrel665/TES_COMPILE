Requested UI/macro fixes applied:

1. Removed Macro Settings button/menu and deleted page_macro_settings.xml.
2. Combined Trigger Size and Trigger Opacity controls into Macro Manager below Interval Tap and Duration Tap.
3. Removed Tap / Repeat Tap / Double Tap / Release Tap mode buttons.
4. Added only Hide and Close buttons to the main overlay panel.
5. Removed automatic panel timeout and bubble window behavior. Hide simply hides the panel; notification can reopen it. Close stops the overlay service.
6. Trigger no longer draws crosshair/guide lines.
7. Trigger can be dragged while Macro Manager is open, and a normal click now toggles the macro instead of being blocked by the move mode.
8. Macro worker performs an immediate Android input tap, then repeats while enabled. Clicking Trigger again stops it.
9. Sensitivity bridge swaps X/Y values when starting the native worker to match the reported device behavior where the controls were affecting the opposite axis.
10. Native worker curve is fixed to LINEAR 1:1 (factor 1.0); no acceleration/deceleration preset is applied.

Build note:
The local environment could not run the Gradle build because Gradle 8.1.1 was not cached and services.gradle.org was unreachable. XML parsing and Java brace checks were performed after the edits.
